# Browser and Terminal App Choices

## Browser

NetSurf was installed earlier, but it does not provide the JavaScript capability needed for Google auth flows.

Falkon was selected as the lightweight auth-capable browser and set as the default for:

- `text/html`
- `http`
- `https`

Default desktop entry:

```text
org.kde.falkon.desktop
```
